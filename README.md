# AI Chat

간단한 캐릭터 기반 챗 웹앱입니다. 사용자는 캐릭터를 만들고, 설정집을 구성하고, AI와 대화를 이어가며 자신만의 캐릭터 대화 경험을 만들 수 있습니다.

## 주요 기능

- 캐릭터 생성 및 수정
- 사용자 프로필 관리
- 대화 기록 보관
- 설정집(세계관/설정 관리) 기반 메모리 기능
- 이미지 첨부 지원
- OpenAI API 연동
- 로컬 저장소 기반 데이터 유지

## 실행 방법

1. 저장소를 로컬로 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. 필요한 경우 브라우저에서 보안 정책에 따라 로컬 실행 환경을 준비합니다.

예:

```bash
python -m http.server 8000
```

그다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

## 사용 방법

### 1) 캐릭터 만들기
- 보관함 탭에서 새 캐릭터를 추가합니다.
- 이름, 세계관, 성격, 첫 인사를 설정합니다.
- 이미지를 선택할 수 있습니다.

### 2) 설정집 만들기
- 설정집에 키워드와 설명을 추가합니다.
- 캐릭터와 연결하면 해당 키워드가 대화 중 언급될 때 AI가 참고합니다.

### 3) 대화 시작
- 캐릭터를 선택해 대화를 시작합니다.
- 대화는 자동으로 로컬 저장소에 유지됩니다.

### 4) AI 연동
- 우측의 ChatGPT 연동 옵션에서 OpenAI API 키를 입력합니다.
- 모델명을 설정하고 대화를 진행합니다.

## 참고 사항

- 데이터는 브라우저의 `localStorage`에 저장됩니다.
- 서버를 통해 백엔드 저장은 하지 않으며, 정적 HTML 기반으로 동작합니다.
- API 키는 브라우저 로컬에만 저장되므로, 보안상 주의가 필요합니다.
